# 08. 차시별 커리큘럼

Ex01~12과 i4h 워크플로를 **15차시**로 배열한 진행표입니다.
주 2회 기준 약 8주, 주 1회 기준 약 15주.

각 차시는 **목표 → 사전 확인 → 실습 → 산출물 → 자가 점검** 구조입니다.
산출물이 나오지 않으면 다음 차시로 넘어가지 마세요. 뒤 차시가 앞 산출물을
전제로 합니다.

---

## 전체 구성

| 파트 | 차시 | 내용 | Isaac Sim | GPU 부하 |
|:--:|:--:|---|:--:|:--:|
| **A. 기초** | 1~6 | Isaac Sim 조작, USD, 로봇 제어, 센서 | 필요 | 낮음 |
| **B. 데이터·규모** | 7~10 | 합성 데이터, 에셋 파이프라인, 병렬화, 캡스톤 | 필요 | 중간 |
| **C. 실전 워크플로** | 11~12 | i4h robotic_surgery 설치와 RL 학습 | 필요 | **높음** |
| **D. 공개 데이터** | 13~14 | 남이 만든 데이터셋 해독과 재생 | 13차시 불필요 | 낮음 |
| **E. 프론티어** | 15 | 현재 장비의 한계와 그 너머 | 불필요 | 없음 |

> **0차시(선택)**: [docs/00 환경 설정](00-환경설정.md)으로 Isaac Sim 설치를
> 마치고 `tools/check_env.py`가 통과해야 1차시를 시작할 수 있습니다.

| | |
|---|---|
| **목표** | SimulationApp 수명주기를 이해하고 첫 씬을 띄운다 |

**자가 점검**

> 첫 실행은 셰이더 컴파일로 수 분 걸립니다. 멈춘 게 아닙니다.

## 12차시 — RL 학습과 VRAM 실측 ⚠️ GPU 부하 최대

| | |
|---|---|
| **목표** | PPO 대규모 병렬 학습을 자기 GPU 한계 안에서 돌린다 |

> **3090 실전 팁 세 가지**: 학습은 항상 `--headless`, 브라우저 닫기,
> 가능하면 모니터를 내장 그래픽으로. 자세한 근거는 [docs/04](04-i4h-설치-RTX3090.md).

## 15차시 — 지금 장비의 천장과 그 너머

**다루는 것**
- RTX 3090으로 **할 수 없는 것**의 구체적 수치 (VRAM, GPU 시간)
- 프론티어 랩이 실제로 하고 있는 연구
- 수술 로봇 자율성 레벨과 현재 위치
- 미해결 과제 목록

**자가 점검**
- [ ] 자기 GPU가 부딪히는 벽이 무엇인지 수치로 말할 수 있다
- [ ] 자율성 Level 0~5에서 현재 기술이 어디인지 안다
- [ ] 관심 주제 3개를 골랐고, 그중 하나는 **지금 장비로 시작 가능**하다
